# 3in

App di allenamento (PWA): schede, calendario, timer di recupero, statistiche e un coach a regole.

- Aprire: servire la cartella con un server statico (`npx serve .`) e visitare `index.html`; funziona offline dopo la prima visita.
- Lavorare sul codice: leggi `docs/ARCHITETTURA.md` (come è fatto), `docs/indice-codice.md` (dove sta cosa), `docs/PIANO.md` (cosa si fa e in che ordine), `docs/coach-mappa-regole.md` (le regole del coach).
- Controllare: `npm install && npm run controlla`.
